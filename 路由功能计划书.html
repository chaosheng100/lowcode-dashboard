一级路由清单

🖥️大屏管理 /dashboard一级
可视化大屏的集中管理入口，负责大屏的创建、编辑、发布与生命周期管理。

🖥️ 大屏管理 /dashboard

  • 大屏列表（卡片/表格视图），支持按名称、标签、状态筛选与搜索
  • 新建大屏（进入设计器）、编辑、复制、删除
  • 发布 / 下线、访问链接与嵌入码（iframe）管理
  • 缩略图预览、最近编辑时间、负责人字段
配置：params:{id} · props:{title} · state:{当前选中大屏}
🔌生态扩展 /extension一级 · 5 二级
大屏能力的向外延伸与生态集成，覆盖报表、轮播、孪生、部署与物联。

报表管理 /extension/report

  • 结构化报表（表格+图表）配置
  • 导出 PDF / Excel、定时推送
配置：params:{reportId}

轮播管理 /extension/carousel

  • 多张大屏轮播计划
  • 播放排期、顺序与时间间隔
配置：state:{playing}

数字孪生 /extension/twin

  • 三维场景 / 设备模型接入
  • 数据到模型的实时可视化映射（预留强能力）
配置：props:{sceneId}

独立部署 /extension/deploy

  • 大屏打包为独立静态站点 / 容器镜像
  • 部署到指定环境并查看状态
配置：state:{deployStatus}

物联组态 /extension/iot

  • IoT 设备点位接入
  • 组态监控画面与告警联动
配置：params:{deviceGroup}
🗄️数据管理 /data一级 · 5 二级
平台的数据接入、加工与流转中枢，支撑大屏的数据来源。

数据源配置 /data/source

  • 数据库 / API / 文件等连接管理
  • 连通性测试与凭证托管
配置：params:{sourceId}

数据集管理 /data/dataset

  • 基于数据源构建数据集
  • 字段映射、清洗、建模（已预置示例页）
配置：params:{datasetId}

数据填报 /data/entry

  • 在线表单填报补录
  • 填报任务与审批流
配置：state:{draft}

消息通道 /data/channel

  • 告警 / 通知通道配置
  • 邮件、钉钉、企业微信等对接
配置：params:{channel}

数据工作流 /data/workflow

  • 数据同步 / 计算 / 调度编排
  • 任务依赖与运维监控
配置：state:{lastRun}
