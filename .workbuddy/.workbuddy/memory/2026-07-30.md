## 后端 npm run build “编译报错” 根因与修复
- 现象：`npm run build`（后端，= `nest build`）报错 `Error [safe-delete][SAFE_DELETE_BULK_CONFIRM_REQUIRED] {"count":184,"threshold":50,...}`，并非 TS 错误。
- 根因：沙箱 safe-delete 保护禁止单次删除 >50 文件；`nest build` 默认 `deleteOutDir:true` 会先 `rimraf` 清空 `dist`（184 文件）→ 被拦截中断。前端 `vite build` 不受影响（改写而非整目录删除）。
- 修复：`apps/api/nest-cli.json` 的 `compilerOptions.deleteOutDir` 由 `true` 改为 `false`，tsc 改为覆盖写、不再整目录删除 → `npm run build` 通过。**副作用**：删源文件后其 `.js` 残留在 dist（仅 dev 后端可接受；用户在无沙箱真机可改回 `true` 获干净构建）。
- 注：直接 `node node_modules/.bin/nest` 也会因该 shim 是 bash 脚本而 `SyntaxError`，须用 `node node_modules/@nestjs/cli/bin/nest.js build` 或 `npm run build`。
