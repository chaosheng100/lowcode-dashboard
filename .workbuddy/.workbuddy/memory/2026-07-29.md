## 数字孪生运行时状态按实例隔离（10:2x 用户反馈"列表之间点击编辑数据串行了"）
- 根因：`useTwinRuntimeStore` 是全局单例，而数字孪生可有多个实例（同屏多个 digitalTwin 组件 + 模块编辑器 TwinPage）。它们共用同一份 `selectedEntityId/predictions/alarms/whatIf/controls/sourceStatus`，导致在 A 列表点击/编辑实体，B 列表的选中态/遥测/预测/告警跟着变 → "数据串行了"。
- 修复边界：场景几何数据(`twinScenes`)保持全局共享（上次的互通特性不变）；**运行时状态改为按 instanceId 隔离**。
- `twinRuntimeStore.ts` 重写：state 顶层改 `instances: Record<id, TwinInstanceState>`，所有 action 加 `instanceId` 首参；新增 `EMPTY_TWIN_INSTANCE` 稳定空引用 + `ensureInstance` + 聚合选择器 `selectAllAlarms`/`selectAllPredictions`（按实体+级别去重，供全局告警清单汇总）；移除未使用的 `live` 字段。
- `control.ts`：`TwinControlHub` 构造接收 `instanceId`，指令日志写入对应实例。
- `TwinWidget.tsx`：`instanceId = component.id`，`rt` 改为 `useTwinRuntimeStore(s=>s.instances[instanceId]) ?? EMPTY`，所有 set 调用带 instanceId；controlRef 懒初始化 `new TwinControlHub(instanceId)`。
- `TwinPage.tsx`：`TWIN_MODULE_INSTANCE='twin-module'` 固定键，同上改造。
- `AlarmListWidget.tsx`：改用 `selectAllAlarms/selectAllPredictions` 聚合所有实例；点击告警仅走 `onPick` 联动 filter（去掉写全局 `setSelectedEntity`，避免跨实例串数据）。
- 验证：tsc --noEmit 0 错；vite build 通过(4631 模块)。改动尚未提交（含上一条未推送的互通修复，待一并推送）。
