## 排错：端口 3000 冲突（EADDRINUSE）
- 现象：`npm run start` 报 `Error: listen EADDRINUSE: address already in use :::3000`。
- 根因：同时跑了多个后端实例（或上一次 `npm run start &` 的 nest 子进程没被杀干净，npm 父进程被 kill 但 node 孙进程仍占端口）。
- 排查：`netstat -ano | grep ':3000'` 找到 LISTENING 的 PID；`tasklist | grep -i node` 确认进程。
- 释放：`taskkill /F /PID <pid>`（Windows）。**同一时间只保留一个后端实例**。
- 注意：Bash 工具里不能直接 `powershell -Command ...`（被安全策略拦截），端口/进程操作走 `netstat`/`tasklist`/`taskkill` 等原生命令。
