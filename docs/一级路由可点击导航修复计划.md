# 一级路由可点击导航修复计划

## 问题

左侧路由树的一级路由（有子节点的父节点，如「生态扩展 / 数据管理 / 组件中心」等）当前不可点击导航：
- 树节点设置了 `selectable: false`，点击整行只触发展开 / 收起，不调用 `selectRoute`，不出现选中态。
- 展开模式与仅图标折叠模式均无法通过点击一级路由进入其页面配置。
- `docs/一级路由展开收起修复计划.md` 记录的是「父节点只展开不导航」的旧行为，与本需求相反，应替换。

## 目标

一级路由可点击导航（进入其页面配置），同时保留展开 / 收起能力：

- 有子节点的一级路由：点击整行 **选中并导航**（`selectRoute`），同时展开 / 收起子级；不再禁止选中。
- 叶子路由（含一级叶子 `/help`）：保持点击导航。
- 仅图标折叠模式：一级父路由点击展开侧栏并导航；叶子一级路由点击导航。
- 视觉上父节点恢复可点击样式：指针、hover、选中胶囊均正常呈现。

## 实现

### `src/data/routes/RoutePanel.tsx`

- `toTreeData`：父节点改为 `selectable: true`，去掉 `rt-parent` 的不可选中语义（className 保留用于视觉与角标样式）。
- 展开 Tree 的 `onSelect`：父节点也调用 `selectRoute(key)`（移除 `!parentIdSet.has(key)` 拦截），点击父节点即导航；展开 / 收起由 `expandAction="click"` 继续负责。
- `selectedKeys`：父节点不再被过滤，选中父节点时正常高亮。
- 折叠模式：父节点点击改为「展开侧栏 + `selectRoute(r.id)`」，与展开模式行为一致。

### `src/styles/global.css`

- 移除父节点「分组标题」样式：`.route-area .rt-parent .ant-tree-node-content-wrapper { cursor: default }` 与选中透明背景，改为与叶子一致的可点击样式。
- 父节点角标 `.rt-badge` 保留（展开数提示），选中态随 `.active` / antd selected 高亮。

### `docs/一级路由展开收起修复计划.md`

- 内容已与新需求冲突，替换为指向本计划的说明（或直接更新为「父节点可点击导航 + 展开收起」行为约定）。

## 验证

- `npm run typecheck` 通过。
- 启动 Vite 开发服务器人工验证：点击一级路由可导航到其配置面板并出现选中态，同时子级可展开 / 收起；折叠模式点击一级路由可导航。
